# w11-cy1: Student dashboard (react-router, props, PropTypes, useEffect)

## 1. What the question asks
React Router v6 app (`Routes`, `Route element=`, `Link`). Files: `App.js`, `components/Navbar.jsx`, `components/Marks.jsx` (CSS files imported by each must exist).
- `App` owns the `<BrowserRouter>`, renders `<Navbar studentName=...>` and routes:
  - `/` home: `h1#home-title` `Welcome to Your Dashboard`, `p#home-student-name` `Student: <name>` (the name string the test expects), department, message
  - `/marks` -> `<Marks marks={marks} />`.
- `Navbar` (prop `studentName`): `nav#navbar`, brand `Student Dashboard`, `Link` `Home` (`/`) and `Link` `Marks` (`/marks`), and `Welcome, <studentName>`.
- `Marks` (prop `marks`, array of `{subject, score}`): `h1#marks-title` `Subject Marks`, each item `.mark-item` (subject + `Score: n`), `p#total-score` `Total Score: <sum>`.
- Both components set `propTypes`.
- Marks data: Mathematics 92, Physics 85, Chemistry 78, Computer Science 96, English 88 (sum 439).

## 2. What each test checks
- App (no router wrapper by the test): `getByText("Welcome to Your Dashboard")`, `getByText("Student: <name>")`.
- Navbar inside `MemoryRouter`: `Student Dashboard`, `Home`, `Marks`, `Welcome, <name>`; `Navbar.propTypes` has `studentName`.
- Marks inside `MemoryRouter`: `Subject Marks`; `document.querySelectorAll('.mark-item').length === 5`; `Total Score: 439`; `Marks.propTypes` has `marks`.

## 3. The original submission
Passes 10/10. Right: Router lives inside `App` (so the App test works with no wrapper, and the Navbar/Marks tests supply their own `MemoryRouter`); sum with `reduce`; keys on list; PropTypes `arrayOf(shape(...))`.
Fragile:
- If `BrowserRouter` is moved into `index.js`, the App test crashes (`Link` outside Router); if you wrap in both places you get a nested-router error.
- `getByText("Marks")` is exact, so the home paragraph "...explore your Marks." doesn't match but would with a regex. Beware duplicate `Home`/`Marks` strings.
- The total is stored via `useState` + `useEffect`; it works because RTL flushes effects in `render`, but computing it directly during render is simpler and safer. The `console.log` in the effect is the "visited page" requirement of the original statement.

## 4. Common mistakes
- Router placement (see above); Router v5 syntax (`Switch`, `component=`) with v6 installed.
- Using `<a href>` instead of `Link`.
- Text split into several elements (`Total Score:` and the number apart).
- Score text format; total not numeric sum.
- Missing `.mark-item` class or extra elements with that class.
- Defining `propTypes` for the wrong prop name.

## 5. Approach in 5 steps
1. Define `marks` array in `App`; wrap everything in `BrowserRouter`.
2. Build `Navbar` with two `Link`s and the welcome text; add propTypes.
3. Build `Marks`: map to `.mark-item`, compute total (reduce), add propTypes.
4. In `App`: `Routes` with `/` (inline home JSX) and `/marks`.
5. Check every exact string and id in the spec.
